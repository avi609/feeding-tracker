# 🍼 מעקב האכלות

אפליקציית ווב קלה לטלפון לתיעוד האכלות תינוק, בעברית (RTL), ללא שרת וללא התקנה.

## יכולות
- רישום האכלה בשלוש אפשרויות: **הנקה בלבד**, **בקבוק בלבד** (עם כמות במ״ל), **הנקה + בקבוק** (עם כמות במ״ל ידנית)
- בחירת שעה (ברירת מחדל: עכשיו) – אפשר לרשום גם בדיעבד
- דשבורד: זמן שעבר מההאכלה האחרונה, הערכת זמן להאכלה הבאה, סיכום יומי, גרף 7 ימים, היסטוריה לפי ימים
- עריכה ומחיקה בלחיצה על האכלה
- ייצוא ל-CSV, גיבוי ושחזור JSON
- עובד אופליין, מתאים למצב כהה, ניתן להוספה למסך הבית (PWA)
- הנתונים נשמרים מקומית בדפדפן בלבד (`localStorage`)

## הרצה
פתחו את `index.html` בדפדפן, או הפעילו דרך GitHub Pages:
**Settings → Pages → Deploy from a branch → `main` / root**

לאחר מכן פתחו את הכתובת בטלפון ובחרו "הוסף למסך הבית".
